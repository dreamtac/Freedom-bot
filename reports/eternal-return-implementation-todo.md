완료 기준: 등록 유저가 자동 갱신되며 `/전적`은 다음 5분 주기를 기다리지 않는다.

완료했다. 로컬 관리 도구와 독립 모니터를 추가했고, 시작 즉시 및 기본 5분마다 등록 유저를 확인한다. 수동·자동 요청은 UID별 최신 수집 작업을 공유한다.

## 5. 시즌 프로필과 분석 계산

### 시즌 프로필

- [x] `Season` 실제 응답의 기간·활성 조건으로 현재 시즌을 식별한다. 최근 경기의 시즌을 현재 시즌으로 대체하지 않는다.
- [x] 사용자 통계·랭크 API의 실제 응답을 개인키로 확인하고 캐시 모델을 확정한다.
- [x] 해당 시즌의 공식 티어 기준과 상위 티어 순위 조건을 확인해 RP·순위 → 티어 표시를 구현한다. 시즌별 기준을 관리하고 근거 없는 티어는 표시하지 않는다.
- [x] 시즌 랭크의 실험체별 플레이 횟수로 TOP 5를 정렬한다. 동률과 5개 미만인 경우를 처리한다.
- [x] 검색 유저 자신의 현재 시즌·랭크·실험체별 평균 `damageToPlayer`를 계산한다.
- [x] 시즌 경기 수와 피해량 유효 표본 수를 구분하고 부분 수집·데이터 없음 상태를 만든다.
- [x] `/전적`의 티어 표시와 `/시즌전적`이 같은 프로필 캐시를 사용하게 한다. 초기 TTL은 5분을 기본안으로 하며, `/시즌전적` 직접 요청은 프로필 갱신을 우선 요청한다.
- [x] 새 시즌·랭크 기록 없음·통계 실패·티어 경계·결측 피해량을 검증한다.

### 본인의 과거·최근 비교

- [x] 초기 기본 비교를 같은 모드의 최근 50경기와 그 이전 50경기로 제안하고 구간이 겹치지 않게 한다.
- [x] 시즌·모드 필터를 적용하고 실험체별로 같은 두 구간의 기록을 묶는다. 모드별 표본 부족과 패치 경계를 표시한다.
- [x] 평균 피해량·순위·킬·데스·어시스트·팀킬과 증감량을 계산한다. 평균 순위는 작아질수록 좋은 값임을 표시한다.
- [x] 결측치는 항목별 분모에서 제외하고 실험체별·항목별 표본 수를 함께 반환한다. 적은 표본을 충분한 근거처럼 평가하지 않는다.
- [x] 유저 외부 비교용 평균이나 잘함·못함 등급은 계산하지 않는다.
- [x] 손으로 검산 가능한 표본으로 구간 분리·모드 필터·평균·증감·유효 분모를 검증한다.

완료 기준: TOP 5는 시즌 플레이 횟수 기준이며, 평균 피해량은 본인 기록만 사용하고 수집 범위를 숨기지 않는다.

완료했다. 공식 Season 활성 플래그, 현재 시즌 티어 기준, 5분 프로필 캐시, TOP 5 보완, 본인 피해량 평균과 최근 50경기/이전 50경기 분석 계산을 구현했다. Discord 화면 연결은 6단계에서 진행한다.
